# Q: распиши подробнее третий пункт исправлений

## Answer

Expanded from graph vocab: [api, auth, current, fetch, local, login, logout, set, token, user]. Current flow: login returns JWT to JavaScript; auth.js writes it to localStorage; core.js reads it on reload and adds Authorization to every request; logout only removes local state. Recommended for this same-origin SPA: login sets JWT in HttpOnly Secure SameSite cookie and does not return it to JS; browser sends cookie automatically; get_current_user reads cookie, optionally retaining Bearer fallback for API clients; add server logout that deletes the matching cookie; frontend removes token/setToken/localStorage and probes /auth/me on startup. Cookie flags do not eliminate XSS and introduce CSRF considerations: explicit CORS origins, SameSite, Origin/Referer or signed CSRF token, HTTPS, and no state-changing GET. Tests must verify Set-Cookie flags, cookie-authenticated /me, logout, expiry and isolation because module-scoped TestClient persists cookies.
