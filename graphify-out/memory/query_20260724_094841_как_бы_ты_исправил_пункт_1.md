# Q: Как бы ты исправил пункт 1?

## Answer

Expanded from graph vocab: [auth, current, exception, handler, http, response, status, user]. В get_current_user HTTPException уже содержит WWW-Authenticate: Bearer, но глобальный http_exception_handler создаёт новый JSONResponse и не переносит exc.headers. Минимальное исправление в app/exceptions.py: передать headers=exc.headers в JSONResponse. Формат error-envelope и status_code сохраняются. Добавить тест GET /api/v1/auth/me без или с невалидным Bearer token: status 401, response.headers['www-authenticate'] == 'Bearer', прежний JSON error.
