# Запуск EnglishProject локально

Цель — за один заход довести пользователя до открытой в браузере рабочей страницы,
а не просто выполнить команду запуска. Отчёт о состоянии базы и предупреждения
в конце так же обязательны, как сам старт: без них человек откроет приложение,
не увидит картинок у старых слов и решит, что всё сломано.

## 1. Предполётная проверка

Выполни разом, одним вызовом:

```bash
python3 --version
python3 -c "import fastapi, sqlalchemy, httpx, groq; print('зависимости на месте')"
test -f .env && echo ".env есть" || echo ".env ОТСУТСТВУЕТ"
```

Как читать результат:

- **`.env` отсутствует** — приложение не стартует: `app/database.py` падает на
  `DATABASE_URL.startswith(...)`, когда переменной нет. Скопируй шаблон
  (`cp .env.example .env`) и скажи пользователю, что `SECRET_KEY` и
  `DATABASE_URL` надо заполнить. `GROQ_API_KEY` можно оставить пустым —
  тогда фразы соберёт офлайн-генератор, а оценка описания уйдёт в
  снисходительную офлайн-проверку.
- **Не хватает зависимостей** — ставь из `requirements.txt`. Файл в кодировке
  **UTF-16 LE**, поэтому `cat` показывает мусор; `pip install -r` его читает
  нормально, а вот `grep`/`sed` по нему работать не будут.
- **Python 3.9** — рабочая версия на этой машине. Код использует
  `from __future__ import annotations`, чтобы синтаксис `str | None` не падал
  на 3.9. Если добавляешь модуль с такими аннотациями, этот импорт обязателен.

Отдельно про venv: в `CLAUDE.md` описан Windows-venv под WSL
(`venv/Scripts/...`, не `venv/bin/...`). На macOS его нет — работай системным
`python3`, пакеты уже установлены.

## 2. Свободен ли порт

```bash
lsof -nP -iTCP:8000 -sTCP:LISTEN 2>/dev/null | tail -3 || echo "порт 8000 свободен"
```

Занят — бери 8001 и дальше подставляй его же. Не убивай чужой процесс на порту,
не спросив: там может висеть что-то нужное пользователю.

## 3. Старт

Запускай **в фоне** (`run_in_background: true`), иначе заблокируешь себе сессию:

```bash
python3 -m uvicorn app.main:app --reload --port 8000 --host 127.0.0.1
```

`--reload` нужен: пользователь почти всегда просит что-то поправить по ходу
проверки, и с ним правки подхватываются без перезапуска.

Запомни ID фоновой задачи — им же потом гасить сервер через `TaskStop`.

## 4. Дождись готовности и проверь

Не спи фиксированное время — жди условия:

```bash
until curl -s -o /dev/null http://127.0.0.1:8000/app/ 2>/dev/null; do sleep 0.5; done
curl -s -o /dev/null -w "фронтенд /app/: HTTP %{http_code}\n" http://127.0.0.1:8000/app/
curl -s -o /dev/null -w "API /api/v1/words: HTTP %{http_code}\n" http://127.0.0.1:8000/api/v1/words
```

Здоровый ответ: `/app/` → **200**, `/api/v1/words` → **401**. Четыреста первый
здесь — норма, а не поломка: эндпоинт под авторизацией и без токена обязан
отвечать именно так. Если увидел 200 на `/api/v1/words` — что-то не то с защитой.

Стартовые ошибки ищи в файле вывода фоновой задачи.

## 5. Состояние базы — обязательный шаг

Без этого пользователь не поймёт, что увидит на экране:

```bash
python3 - <<'PY'
import sqlite3, os
from dotenv import load_dotenv; load_dotenv()
url = os.getenv("DATABASE_URL","")
if not url.startswith("sqlite"):
    print("база не SQLite:", url.split("://")[0], "— проверь, что сервер БД поднят")
else:
    con = sqlite3.connect(url.replace("sqlite:///",""))
    users = con.execute("SELECT COUNT(*) FROM users").fetchone()[0]
    total = con.execute("SELECT COUNT(*) FROM words").fetchone()[0]
    img   = con.execute("SELECT COUNT(*) FROM words WHERE image_url IS NOT NULL").fetchone()[0]
    print(f"пользователей {users}, слов {total}, из них с картинкой {img}")
    print("провайдер картинок:", os.getenv("IMAGE_PROVIDER") or "pollinations (по умолчанию)")
    for (e,) in con.execute("SELECT email FROM users ORDER BY id"): print("  -", e)
PY
```

## 6. Что сказать пользователю

Ссылка крупно и первой строкой: **http://127.0.0.1:8000/app/**

Дальше — только те предупреждения, которые реально следуют из отчёта шага 5:

- **Картинки есть только у новых слов.** Если слов с картинкой заметно меньше,
  чем всего, скажи прямо: старые слова заводились до появления сцен, у них нет
  ни `scene_prompt`, ни изображения. Чтобы проверить режим описания, нужно
  добавить новое слово. Для слов без картинки режим описания сам откатывается
  на викторину — сессия не рвётся, но картинок там не будет.
- **Скорость генерации.** На Pollinations картинка рисуется 25–30 секунд
  (очередь бесплатного анонимного тарифа). Слово при этом добавляется мгновенно,
  в карточке пульсирует заглушка «рисуем картинку…», фронт сам опрашивает
  готовность — перезагружать страницу не нужно. На Cloudflare те же 3–5 секунд.
- **Под каким аккаунтом заходить** — назови существующие email из отчёта.
- **Режимы тренировки** — селектор справа вверху на экране учёбы:
  🖼 Описание (по умолчанию), 🔤 Выбор, ✍️ Ввод. Выбор запоминается в localStorage.

В конце предложи погасить сервер, когда проверка закончится.

## 7. Остановка

`TaskStop` с ID фоновой задачи. Не оставляй сервер висеть после того, как
пользователь сказал, что закончил.

## Смежные операции

**Тесты** — идут офлайн и не трогают рабочую базу (`tests/conftest.py`
подменяет `get_db` и `crud_words.SessionLocal` глобально, а внешние вызовы
глушит фикстура `offline_mode`):

```bash
python3 -m pytest -q                       # весь набор
python3 -m pytest -q tests/unit/test_describe.py
```

**Миграции** — на SQLite схема достраивается сама при старте
(`Base.metadata.create_all` плюс блок `ALTER TABLE` в `app/main.py`), поэтому
локально Alembic обычно не нужен. Он обязателен для PostgreSQL:

```bash
alembic upgrade head
alembic revision --autogenerate -m "описание"   # после правок app/models.py
```

**Переключение провайдера картинок** — через `.env`:

```
IMAGE_PROVIDER=pollinations   # без ключа, медленно, для разработки
IMAGE_PROVIDER=cloudflare     # нужны CLOUDFLARE_ACCOUNT_ID и CLOUDFLARE_API_TOKEN
IMAGE_PROVIDER=off            # картинки не генерируются вовсе
```

**Кеш картинок** — `media/scenes/`, вне git. Файл называется хешем описания
сцены, поэтому одинаковые сцены не генерируются дважды. Каталог можно удалить
целиком: он восстановится генерацией, потеряется только уже оплаченная работа.
Записи в базе при этом останутся с битыми `image_url` — если чистишь кеш,
обнули и их: `UPDATE words SET image_url=NULL, image_status='none'`.

## Частые поломки

| Симптом | Причина |
|---|---|
| `AttributeError: 'NoneType' object has no attribute 'startswith'` при старте | нет `.env` или в нём пустой `DATABASE_URL` |
| `TypeError: unsupported operand type(s) for \|` | в новом модуле забыт `from __future__ import annotations` (Python 3.9) |
| Слово добавляется, картинка не появляется никогда | `IMAGE_PROVIDER=off`, либо провайдер вернул ошибку — ищи `WARNING` от `app.image_generator` в логе |
| Оценка описания всегда «проверка ИИ недоступна» | пустой `GROQ_API_KEY` в `.env` |
| Порт занят после прошлого запуска | предыдущий uvicorn не погашен — найди через `lsof` и останови |
